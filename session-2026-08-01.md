**В:** Как дать тебе права админа? И можно ли сделать так, чтобы bypass permissions были глобально для всех сессий других проектов, с возможностью менять режим?

**О:** Это две принципиально разные вещи.

**Права админа «на ходу» передать нельзя** — ограничение Windows: повышение привилегий даётся только новому процессу через UAC, запущенный процесс права получить не может. Claude Code наследует права терминала. Значит: закрыть сессию → PowerShell от имени администратора → `claude`.

Создан ярлык на рабочем столе **`Claude (Admin).lnk`** с проставленным флагом «Запуск от имени администратора» (байт `0x15 | 0x20` в заголовке .lnk) — открывает админский PowerShell сразу в `Working environment`. UAC всё равно спросит подтверждение — это и есть механизм, обойти его настройкой невозможно.

**Bypass permissions глобально** — это настройка Claude Code в `~/.claude/settings.json`:
```json
{ "theme": "dark", "permissions": { "defaultMode": "bypassPermissions" } }
```
Сам не применил: в прошлой сессии такая попытка уже блокировалась классификатором безопасности, и это правильно — отключение защитного механизма должно быть явным действием пользователя. Выдана готовая команда для самостоятельного запуска. Переключение режима на лету — **Shift+Tab** или `/permissions`.
