## 1. Bypass permissions глобально (один раз, для всех проектов)

Выполнить в **обычном** PowerShell (админ не нужен):

```powershell
$p = "$env:USERPROFILE\.claude\settings.json"
$j = Get-Content $p -Raw | ConvertFrom-Json
$j | Add-Member -NotePropertyName permissions -NotePropertyValue ([pscustomobject]@{ defaultMode = "bypassPermissions" }) -Force
$j | ConvertTo-Json -Depth 10 | Set-Content $p -Encoding utf8
Get-Content $p
```

Должно вывести:
```json
{
    "theme":  "dark",
    "permissions":  {
        "defaultMode":  "bypassPermissions"
    }
}
```

Переключать режим потом: **Shift+Tab** в сессии или команда `/permissions`.

## 5. Посмотреть Docker старой системы (диск F:, нужен админ)

```powershell
Mount-VHD -Path "F:\ProgramData\DockerDesktop\vm-data\DockerDesktop.vhdx" -ReadOnly
Get-Disk | Where-Object { $_.Location -like "*DockerDesktop*" }
```
Отмонтировать после:
```powershell
Dismount-VHD -Path "F:\ProgramData\DockerDesktop\vm-data\DockerDesktop.vhdx"
```

Доступ к профилю старого пользователя:
```powershell
takeown /F "F:\Users\Unknown" /R /D Y
icacls "F:\Users\Unknown" /grant "$env:USERNAME:(OI)(CI)F" /T
```

> ⚠️ Перед отключением F: проверить тома Knowledge Factory (`kf-postgres`, `kf-qdrant`, `kf-minio`) — их архивов на E: не найдено. См. `NEXT-SESSION-START-HERE.md`, п. 3.3.
