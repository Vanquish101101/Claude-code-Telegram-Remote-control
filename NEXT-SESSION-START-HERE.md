## 6. Грабли этой машины (проверено на практике)

- **Не обновлять Docker Desktop** — только ≤ 4.24.2 (Windows build 19044.1165). Store-версия WSL не ставится (`WSL_E_OS_NOT_SUPPORTED`), только inbox WSL2 + MSI-ядро. Аварийный комплект: `C:\Users\AI Developments\Downloads\` (не удалять).
- **Квадратные скобки `[ ]` в именах папок** — PowerShell трактует как wildcard, `Test-Path` молча возвращает `False` для существующих файлов. Использовать круглые.
- **Нативный установщик Claude Code сносит npm-версию** (и ломает инструменты запущенной сессии). После установки одного — переустановить другой, нужны оба.
- `winget install` не элевирует сторонние установщики → при коде 1 запускать `.exe` из кэша winget напрямую.
- Тема обновления Windows/активации закрыта — машина осознанно используется как песочница, не поднимать.
