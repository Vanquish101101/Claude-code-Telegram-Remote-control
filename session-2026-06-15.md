**Причина:** в `.env` нет `ANTHROPIC_API_KEY` — бот использует OAuth (`~/.claude/.credentials.json`), который истекает каждые ~8 часов.
- Комментарий в .env: "CLI subscription mode, без API ключа, не тратит токены"
- Но v1.3.0 игнорирует `USE_SDK=false` — всегда SDK-режим
- При истечении OAuth → crash loop с exit code 1

**Решение не применялось** — пользователь оставил subscription mode. Бот работает в пределах 8ч окна и рестартует когда OAuth истекает.
